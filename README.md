# Employee Management Web Application

A simple web-based Employee Management System built using **Python and Flask**.  
This application allows users to add, view, and delete employee records through a browser-based interface.

---

## Features

- Add employee details using a web form  
- View all employee records in a table  
- Delete employee records with confirmation  
- Persistent data storage using JSON file  
- Clean and professional user interface  

---

## How to Run the Project

1. Clone the repository  
   git clone <repository-link>

2. Open the project folder  
   cd employee_web_app

3. Install Flask  
   pip install flask

4. Run the application  
   python app.py

5. Open the browser and visit  
   http://127.0.0.1:5000
